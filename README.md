# Adidas Corporate Finance Case Study

University project analyzing financing choices, solvency & credit metrics, and optimal capital structure for Adidas.

## What I did
- Collected raw data from Adidas reports/website and cleaned it into a working dataset.
- Built an Excel model for WACC and target capital structure.
- Computed D/E and other solvency ratios; benchmarked peers and linked ratio trends to rating changes.
- Assessed dividend vs. buyback policy and wrote a concise financing recommendation.
